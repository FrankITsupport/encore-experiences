# VenueBox admin editing guide

Sign in at **https://venuebox.co.ke/admin** with the admin email and password. Use the tabs at the top to edit Events, Hero slides, and Equipment. Select **Sign out** when finished.

## Add an event

1. Open **Events** and select **+ New event**. Enter a title. The URL slug fills automatically; edit it if needed using lowercase letters, numbers, and hyphens.
2. Add the date, location, short summary, and write-up. Separate paragraphs in the write-up with a blank line. Upload a cover image.
3. Leave **Publish event** unchecked and select **Save event**. This creates a draft that visitors cannot see.
4. Under **Gallery photos**, write a description for the first photo, then upload it. Add more photos the same way. Optional captions appear with photos. Use **Move up** and **Move down** to set their order.
5. Check **Publish event** and select **Save event** again. Confirm it appears at **https://venuebox.co.ke/events** and open the event page. To hide it later, uncheck Publish event and save.

Every published event needs a title, short summary, cover image, and at least one gallery photo with a description. The editor will show a message if anything is missing.

## Change the homepage hero

Open **Hero**. Select an existing slide to change it or choose **+ New slide**. Choose an image or video, upload the media, and enter the headline and supporting text. A video also needs a poster image. Check **Show this slide**, select **Save slide**, and use **Up** or **Down** to set the order. Visit the homepage to check the result.

Hero images can be up to 12 MB and videos up to 50 MB in the app. The hosting account may enforce a smaller limit; if an upload fails, try a smaller file and report the error.

## Change equipment

Open **Equipment** and select an item. Edit its name, description, tag, or image, then select **Save equipment**. Use **Up** and **Down** to reorder items. The **Publish equipment** checkbox controls whether visitors see the item.

Uploaded files remain in the hosting account after a content record is deleted. Ask the site maintainer before removing files in cPanel's `uploads/` folder.
